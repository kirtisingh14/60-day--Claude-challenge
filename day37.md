# Day 37 – Build Task Compass

## 📌 Overview

Welcome to **Day 37** of my **60 Days of Claude AI Mastery Challenge**.

In this project, I built **Task Compass**, an **AI-powered task prioritization and productivity assistant** designed to help users organize their work, prioritize tasks intelligently, and stay focused on what matters most. The application analyzes task urgency, importance, deadlines, and effort to generate actionable recommendations and improve productivity.

---

# 🎯 Objectives

* Learn effective task prioritization techniques.
* Organize tasks based on urgency and importance.
* Improve productivity through AI-powered recommendations.
* Reduce decision fatigue with structured planning.
* Visualize workload and progress using interactive dashboards.
* Build better daily planning and time management habits.

# ⚙ Workflow

1. Read the provided learning resources.
2. Watch the solution video.
3. Open Claude.
4. Set Claude effort level to **Low**.
5. Start a new conversation.
6. Paste the **Task Compass** prompt.
7. Generate the complete HTML application.
8. Save the generated HTML file.
9. Open the application in your browser.
10. Review the introduction and application guide.
11. Add or review the generated task list.
12. Prioritize tasks based on urgency and importance.
13. Analyze workload distribution and deadlines.
14. Review AI-generated productivity recommendations.
15. Observe updates to the Productivity Dashboard.
16. Study the Final Productivity Report.

18. Capture screenshots of your results.
