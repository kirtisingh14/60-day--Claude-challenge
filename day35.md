# Day 35 – Build Prompt Puzzle 🧩

## Overview

Welcome to **Day 35** of my **60-Day Claude AI Mastery Challenge**.

Today's project focused on building an interactive **Prompt Puzzle** application using Claude AI. The objective was to strengthen prompt engineering skills by solving prompt-related puzzles, understanding prompt structures, and learning how different prompt components influence AI-generated responses.

This project demonstrates how AI can be used to create engaging educational games that make learning prompt engineering both interactive and enjoyable.

---

## Objectives

* Learn advanced prompt engineering concepts.
* Build an interactive HTML application using Claude AI.
* Improve logical thinking through prompt-based puzzles.
* Understand how prompt wording affects AI outputs.
* Practice analyzing and refining prompts.

---

## Features

* 🧩 Interactive Prompt Puzzle Game
* 🎯 Multiple randomized puzzle challenges
* 💡 Hint system for difficult puzzles
* 📊 Progress tracking
* ⭐ Score calculation
* 🎨 Multiple UI themes
* 🔄 Replay with new puzzle sets
* 📚 Learning summary after each completed puzzle
* 📱 Responsive design

## Key Learnings

* Effective prompts require clarity and sufficient context.
* Small wording changes can significantly impact AI responses.
* Prompt engineering is an iterative process of testing and refinement.
* Breaking complex tasks into structured prompts improves output quality.
* Interactive learning makes prompt engineering easier to understand.
