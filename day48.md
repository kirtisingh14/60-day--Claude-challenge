# Day 48 – Build The Verdict Engine

##  Overview

Welcome to **Day 48** of my **60 Days of Claude AI Mastery Challenge**.

In this project, I built **The Verdict Engine**, an **AI-powered decision analysis and reasoning platform** designed to evaluate complex scenarios, compare multiple options, analyze evidence, and generate structured, unbiased recommendations. The application demonstrates how AI can support critical thinking and decision-making by providing transparent reasoning and actionable insights.

# ⚙ Workflow

1. Read the provided learning resources.
2. Watch the solution video.
3. Open Claude.
4. Set Claude effort level to **Low**.
5. Start a new conversation.
6. Paste the **Verdict Engine** prompt.
7. Answer Claude's onboarding questions.
8. Generate the complete HTML application.
9. Save the generated HTML file.
10. Open the application locally in your browser.
11. Select or generate a decision-making scenario.
12. Analyze the available evidence and context.
13. Compare multiple options and evaluate trade-offs.
14. Review AI-generated reasoning and recommendations.
15. Observe the confidence score and final verdict.
16. Explore alternative decisions and their potential outcomes.
17. Replay the simulation using different scenarios.
18. Capture screenshots of your results.
19. Upload the HTML file, screenshots, and documentation to your GitHub repository.
