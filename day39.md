# Day 39 – Build PDF Splitter & Merger

## 📌 Overview

Welcome to **Day 39** of my **60 Days of Claude AI Mastery Challenge**.

In this project, I built an **AI-powered PDF Splitter & Merger** application that enables users to efficiently split, merge, organize, and manage PDF documents through an intuitive interface. The application streamlines document handling with AI-assisted workflows, making PDF management faster, more organized, and user-friendly.

---

# 🎯 Objectives

* Learn how to build an interactive document management application.
* Split PDF files into individual pages or custom page ranges.
* Merge multiple PDF documents into a single file.
* Reorder PDF pages before exporting.
* Improve productivity through an intuitive user interface.
* Explore AI-assisted document processing workflows.

# ⚙ Workflow

1. Read the provided learning resources.
2. Watch the solution video.
3. Open Claude.
4. Set Claude effort level to **Low**.
5. Start a new conversation.
6. Paste the **PDF Splitter & Merger** prompt.
7. Generate the complete HTML application.
8. Save the generated HTML file.
9. Open the application in your browser.
10. Upload one or more PDF files.
11. Choose whether to split or merge documents.
12. Select custom page ranges or reorder pages.
13. Preview the processed document.
14. Apply the desired operation.
15. Download the generated PDF.
16. Test multiple document-processing scenarios.
17. Capture screenshots of the application and results.
18. Upload the HTML file, screenshots, and documentation to your GitHub repository.
