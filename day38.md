# Day 38 – Build Typing Speed Studio

## 📌 Overview

Welcome to **Day 38** of my **60 Days of Claude AI Mastery Challenge**.

In this project, I built **Typing Speed Studio**, an **AI-powered typing practice and performance analysis application** designed to help users improve their typing speed, accuracy, and consistency. The application provides interactive typing challenges, real-time performance metrics, personalized feedback, and AI-generated recommendations to enhance typing proficiency.

---

# 🎯 Objectives

* Improve typing speed and accuracy through interactive exercises.
* Analyze typing performance using real-time metrics.
* Identify common typing mistakes and improvement areas.
* Track progress across multiple typing sessions.
* Develop better keyboard familiarity and muscle memory.
* Use AI-powered insights to optimize typing performance.

---

* ⌨️ Interactive Typing Practice

# ⚙ Workflow

1. Read the provided learning resources.
2. Watch the solution video.
3. Open Claude.
4. Set Claude effort level to **Low**.
5. Start a new conversation.
6. Paste the **Typing Speed Studio** prompt.
7. Generate the complete HTML application.
8. Save the generated HTML file.
9. Open the application in your browser.
10. Choose a typing difficulty level.
11. Start the typing challenge.
12. Type the displayed text within the allotted time.
13. Monitor live WPM, accuracy, and error count.
14. Complete the typing session.
15. Review AI-generated performance feedback.
16. Analyze your strengths and areas for improvement.
17. Replay the typing test to improve your score.
18. Capture screenshots of the results.
19. Upload the HTML file, screenshots, and documentation to your GitHub repository.
